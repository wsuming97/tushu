# 可信转化文案核验优化技能 (Copywriting Verify & Optimize)

把商业文案创作视为一个严密的闭环系统：先形成初稿，再经由**事实核验、6维度量化评分、平台合规风控审查、高转化重构与复评分**。**只有在第二步（事实核验）与第三步（合规审查）全部审核完毕并通过后，才允许在文案素材库（`copywriting-library`）中正式入库保留。**

---

## 🎯 一、四大核心交付指标 (The 4 Core Objectives)

任何交付的文案，必须在结构和措辞上同时满足以下四大指标：

1. **用户能看懂（通俗具象 · 降维沟通）**
   - 严禁晦涩学术术语、空泛大词；
   - 用中国老百姓柴米油盐的具体生活细节（如“买菜算几毛钱、给孩子买房付首付、买衣服放购物车想三天”）去翻译深刻的人生哲学与书籍观点。
2. **用户愿意停留（层层递进 · 防掉人设计）**
   - 严格遵循**“剥洋葱式叙事模型”**，每 60~90 秒释放一个新认知爆点，绝不车轱辘话重复；
   - 配合三景深叙事画面（前景细节 + 中景人物 + 后景氛围），让用户沉浸其中。
3. **用户愿意互动（温情探讨 · 杜绝绑架）**
   - 设置“经验分享型、心愿表达型”的温暖探讨议题，激发中老年女性和年轻子女的表达欲；
   - **严禁道德绑架、严禁设置非黑即白的极端对立站队**。
4. **用户愿意转发（利他价值 · 社交货币）**
   - 击中“两代女性的相互关爱与体谅”（女儿心疼母亲操劳一生转给妈妈、母亲渴望自立从容转给闺蜜）；
   - 提供极高的认知增量与决策参考价值，让用户觉得“转发给家人朋友是在帮他们”。

## 🛡️ 三、微信视频号平台合规与三大视角转变铁律

针对平台风控高压（严打“编造新闻/事件、煽动情绪、恐吓营销、强迫互动”），必须坚守以下铁律：

| 违规红线（一票否决） | 必须转变成的合规高转化视角 |
| :--- | :--- |
| ❌ **严禁编造极端家庭矛盾**<br>（不得将儿女争夺财产、反目成仇、婆媳吵架、看儿媳脸色作为普遍事实） | ✅ **视角转变 1：母亲自立是对家庭最大的负责**<br>把自己的晚年照顾好，不仅自己活得体面，更是给儿女减轻沉重的现实与心理负担。 |
| ❌ **严禁恐吓式/诅咒式卖惨带货**<br>（不得使用“存钱老了是废纸、必定凄凉、不买后悔”等恐吓词） | ✅ **视角转变 2：减少长期透支，让亲情回归纯粹温情**<br>善用专业服务与适老准备，避免两代人因照料而产生无休止的内耗。 |
| ❌ **严禁道德绑架与极端站队强迫互动**<br>（不得在评论区设置“选留给儿女还是自己？测你傻不傻”） | ✅ **视角转变 3：书籍是提供认知决策框架的生活指南**<br>不神化图书，明确它是提前规划住房、资金与照护的自立之书，引导分享温馨生活心愿。 |

## 🔄 四、全流程工作流与素材库准入门禁

```text
【第 1 步：文案初稿生成】
       │ （内部生成，按 6-10m 带货 / 3-6m 流量规格撰写，严禁直接入库）
       ▼
【第 2 步：事实核验与质量优化】
       │ • 按 6 维度评分（满分 100 分，优化后必须达到 85+ 分）
       │ • 建立主张台账，剔除虚假引语、伪造数据与原意漂移
       ▼
【第 3 步：平台合规风控审查】
       │ • 逐条核验四大指标（看懂/停留/互动/转发）
       │ • 彻底清查三大视角转变与违规红线
       ▼
【第 4 步：审核结果呈现与按需归档】
         • 默认直接在对话中输出结构化核验报告与优化后的完整文案；
         • 仅当用户明确确认“保存/归档到素材库”或命令携带 --save 时，
           才正式写入并归档至 copywriting-library/topics/<书名>/ 中永久保留！
```

## 📋 五、完成标准

只有同时满足以下条件才算完成本技能闭环：

1. **初稿和优化稿使用同一量表评分**，且优化稿得分达到 **85 分以上**；
2. **每个关键主张均有明确核验状态**，消除了所有未核实的直接引语或数据；
3. **平台合规风控通过**：无虚假家庭纠纷、无恐吓营销、无道德绑架互动；
4. **满足四大交付指标**：通俗具象、防掉人递进、温情互动、高转发价值；
5. **符合时长标准**（带货款 6~10 分钟 / 流量款 3~6 分钟）；
6. **按需归档交付**：默认提供清晰文本结果，用户授权后安全写入 `copywriting-library/topics/<书名>/`。
