# 🔍 事实与合规主张核验规范 (Verification)

## 一、主张台账与合规审查表

在审核文案时，先抽取所有可能影响**平台合规、用户信任或购买决策**的关键主张，逐条核验：

| 核验类型 | 风险模式（违规/失真） | 安全合规处理方式 |
|---|---|---|
| **1. 引用作者观点** | “上野千鹤子说：存钱是废纸……”（加引号冒充原话） | 去掉引号，改为作者核心关切的转述：“上野千鹤子在书中反复探讨一个问题……” |
| **2. 数据与调查** | “社会学调研发现老人遗产越多儿女越容易反目成仇” | 凡无法溯源一手具体机构和年份的数据，一律删除，改为日常普遍经验的温和表述。 |
| **3. 家庭与代际关系** | “不要给儿女留钱，在儿女家看脸色、争财产” | **三大视角转变**：“在生前把自己照顾妥当，不仅自己体面，更是给儿女减负，让亲情保持纯粹温情。” |
| **4. 金钱与消费定性** | “把钱花光才叫自由，存钱是最大的愚蠢” | 回归理性底线：“把积蓄转化为晚年健康、居住安全与专业照护的选择权，守住生活底线。” |
| **5. 互动与评论区** | “留下你的想法：选全给儿女还是全给自己？” | 转换为温情生活分享：“退休后的日子，你最想为自己添置什么？在评论区一起聊聊。” |
| **6. 图书产品能力** | “读了这本书，彻底解决晚年所有养老疾病问题” | 明确产品属性：“这是一本教女性提前想明白住房、资金、照护与关系的自立决策指南。” |
| **7. 中外制度差异** | 把日本长期照护保险直接当成中国实操政策 | 明确原书日本背景，重点提取可跨国迁移的心理认知与生活准备原则。 |

## 二、核验状态分类

每条抽取出的主张必须标明以下 5 种状态之一：

1. **【已核验】**：原书/一手资料有明确章节和页码支持；
2. **【合理转述】**：符合原作者主旨精神的客观提炼，未加伪造引号；
3. **【主播观点】**：属于合理的个人生活经验或价值判断，表述克制温和；
4. **【合规修正】**：消除了虚假家庭矛盾、恐吓营销等平台风控风险的优化表达；
5. **【删除/剔除】**：违背平台规则、挑起对立或无法查证的断言。

## 三、四大核心交付指标自检清单

在出具核验结论前，必须逐项勾选：

* [ ] **用户能看懂**：是否含有晦涩黑话？生活细节是否足够真实通俗？
* [ ] **用户愿意停留**：是否符合 6-10 分钟（带货）/ 3-6 分钟（流量）时长标准？是否每 90 秒有递进爆点？
* [ ] **用户愿意互动**：置顶首评与结尾是否安全温情、无强迫站队？
* [ ] **用户愿意转发**：是否具有利他价值？是否击中两代女性的情感共鸣？
