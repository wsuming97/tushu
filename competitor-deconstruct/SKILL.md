# 同行文案字数分段与句型结构提炼器 (v2.1)

## 🎯 核心定位与算法界定 (Core Purpose & Boundaries)
本技能定位为 **“基于输入文本字数比例与分句的机械结构分析工具”**。
帮助创作者快速了解同行文案的字数分布节奏、首句句型与篇幅比例。

---

## ⚠️ 算法说明与定性边界
1. **机械比例分段**：按字数占比将输入文本机械划分为四段（前 15%、15%~45%、45%~80%、80%~100%）；
2. **不宣称语义转折识别**：本工具不含深层自然语言心理转折点识别，仅提供字数篇幅与句式槽位参考。

---

## 💻 命令行工具 (CLI Usage)

```bash
# 输入同行文案文本进行字数分段提炼
python scripts/deconstruct_hook.py --text "同行视频文案文本..."
```
