# 评论区置顶与官方答疑助手 (v2.1)

## 🎯 核心定位 (Core Purpose)
解决视频发布后创作者 **“不知道如何正向引导评论区讨论、缺少官方标准答疑话术”** 的痛点。
本技能专注于**“创作者本人公开发布的官方内容资产”**，严守诚信与风控底线，杜绝任何虚假水军与伪造人设立论，杜绝虚假事实归属。

---

## 🛡️ 诚信与合规四大红线 (Compliance Boundaries)
1. **严禁冒充真实读者**：绝不生成伪造的读者个人体验或虚构好评；
2. **严禁人为对立演戏**：绝不制造正反派小号互撕戏码；
3. **严禁虚构事实归属**：书籍作者、出版社等事实信息必须显式由输入提供；未提供时严禁臆造或硬编码为特定学者；
4. **100% 作者官方公开身份**：所有内容均为作者或官方运营账号可公开署名发表的置顶引导词与透明问答草稿。

---

## 💻 命令行工具 (CLI Usage)

```bash
# 生成包含真实作者与出版社的透明问答草稿
python scripts/generate_comments.py \
  --theme "退休与女性自立" \
  --book "一个人的老后" \
  --author "上野千鹤子" \
  --publisher "人民文学出版社" \
  --channel "抖音正版小黄车"
```
