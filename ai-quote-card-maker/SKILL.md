# 贴图号 & 意境金句全案生成 (ai-quote-card-maker)

全自动生成适合微信公众号、小红书发布的图文全套内容。

## 输出归档规范

所有生成的文件统一保存在 **Skill 自身目录**下的 `output/` 中，按日期自动归档：

```
<SKILL_DIR>/output/
├── 2026-08-19/
│   ├── 我以为她心软了_single_story.jpg   # 渲染的高清单故事贴图
│   ├── 我以为她心软了_文案.txt            # 配套深度正文 + 爆款话题标签池
│   ├── 灵魂共鸣_glass.jpg                # 意境金句卡片
│   └── ...
├── 2026-08-20/
└── ...
```

- **默认行为**：不指定 `--out` 参数时，脚本自动归档到 `<SKILL_DIR>/output/YYYY-MM-DD/`。
- **同名文件**：自动追加序号避免覆盖。
- **配套文案 TXT**：Agent 需同时生成同名 `_文案.txt`，保存到同目录。

## 模式一：公众号爆款故事贴图号（贴图 + 配套长文TXT + 标签）

### 1. 生成故事意境背景
使用 `generate_image` 生成具有电影光影感的室内/窗边/办公桌/咖啡杯等柔和明亮或沉静氛围图。

### 2. 渲染单卡片故事贴图
调用 `<SKILL_DIR>/scripts/render_story_card.py`（支持 `**文字**` 红色高亮）：

```bash
python "<SKILL_DIR>/scripts/render_story_card.py" \
  --bg "背景图路径.jpg" \
  --title "我以为她心软了" \
  --story "我处理过一个离婚的案子。\n开庭时她**满脸泪痕**\n我以为她心软了，我心凉半截。"
```

### 3. 本地自动保存配套正文 TXT
将公众号配套深度正文（300-600 字）和 8-12 个爆款标签矩阵写入：
`<SKILL_DIR>/output/YYYY-MM-DD/标题_文案.txt`

### 4. 交付与界面实时预览
同时在对话界面直接展示：
- 贴图成图视觉效果（JPG 链接与图片）
- 配套文案与标签的直接文本预览（方便即刻阅读与复制）
- TXT 与 JPG 文件的本地绝对路径
