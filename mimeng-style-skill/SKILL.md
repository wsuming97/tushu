## 1. 这个 skill 能帮你做什么

`mimeng-style-skill` 是一个中文新媒体观点文写作助手。它适合用来做**爆款标题、第一屏开篇、观点文结构、强情绪表达、文章诊断、全文改写、商业转化文案**和结合语料的写作分析。

### 核心用法
先让 agent 检索机制，再让它输出可直接使用的标题、开篇、结构、改写建议或转化文案。

| 项目 | 说明 |

| **安装名** | `mimeng-style-skill` |
| **调用名** | `$mimeng-style-skill` |
| **内置能力** | 机制库、语料检索、案例检查、标题/开篇/诊断/改写/商业转化工作流 |

## 3. 常用检索与调用工作流

### 3.1 检索真全文与案例卡片
- 调用 `scripts/search_full_text.py "关键词"`，毫秒级检索 956 篇语料的正文真实段落、页码与高亮 Snippet。
- 调用 `scripts/inspect_case.py "标题或ID"`，查看单篇文章的清洗后完整拆解卡片。

### 3.2 写标题或选题
- 判断读者是谁，以及他此刻最强的情绪：**愤怒、焦虑、爽感、共鸣、好奇或亲密**。
- 读取 `references/01_选题方法论.md` 与 `references/02_标题方法论.md`。
- 输出 20 个标题，按冲突、反常识、情绪挑衅、利益承诺、身份点名分组。

### 3.3 写开篇第一屏
- 读取 `references/05_写作框架方法论.md` 与 `references/08_故事结构方法论.md`。
- 把开头控制在 150~300 字内，先给冲突、场景、问题或强烈判断。
- 避免先铺背景、讲大道理、解释概念。第一屏必须让读者知道为什么继续看。

### 3.4 做诊断改写
- 读取 `references/06_写作风格方法论.md` 与 `references/07_金句方法论.md`。
- 检查单句长度、口语颗粒感、反常识金句。
- 针对痛点、第一屏、转折与结尾给可替换文本。

### 3.5 商业带货与合规约束
- 遵循四层递进带货法，但严禁编造家庭矛盾、严禁恐吓营销、严禁伪造引语。必须结合 `copywriting-verify-optimize` 严格核验。
