# 素材方法论

## 第一章：规律总结（这个博主在这个维度上有哪些明显规律）

1. **生活化毛刺细节取胜**：素材极少使用宏大历史叙述，全部聚焦于身边朋友、同事、微信群、菜市场、手机备忘录。
2. **极具画面感的器物与动作**：炒菜的锅铲、洗发白的围裙、深夜翻手机、医院体检单、退烧贴、冷掉的外卖。
3. **原生态对话还原**：保留真实的口头禅、叹气声、反诘句，让素材像在现场发生一样生动。

## 第二章：分类/类型（把规律分成几种类型，每种给出例子）

| 素材类型 | 素材来源与呈现方式 | 作用与效果 |
| :--- | :--- | :--- |
| **1. 身边朋友的真实遭遇** | “我有个朋友李姐/我闺蜜……” | 极速拉近距离，读者觉得真实可信 |
| **2. 日常生活琐碎动作** | 晨光揉腰、深夜叹气、算账省钱、翻找旧物 | 产生强烈的代入感（“这不就是我吗”） |
| **3. 聊天记录/手机备忘录** | 微信截图、转账记录、群内吐槽 | 时代切片感强，天然具备窥私欲 |
| **4. 热点事件与公众人物** | 明星八卦、新闻事件中的关键争议点 | 借势天然流量，引发全网热议 |

## 第三章：操作方法（读者怎么用这个规律写自己的文章）

1. **素材微雕“五感法”**：
   - 写一个人物不要只给形容词（如“她很勤劳”），必须写出：
     - **视觉**：洗得领口发旧的外套、眼角的细纹；
     - **动作**：锅铲在半空中停住、手指在体检单指标上划过；
     - **声音**：深夜关了灯后的一声长叹。
2. **去 AI 抽象化**：把“她经历了岁月的沧桑”改写为“她站在塞满十年没穿旧毛衣的衣柜前，发呆了半天”。

## 第四章：公式/模板（可以直接套用的格式）

- `素材模版 1`：**【时间地点】+【具体人物】+【标志性动作/微小道具】+【一句冲突台词】**
  - *例：昨天下班在电梯口，看到平时雷厉风行的主管，一个人蹲在角落捏着胃药发呆……*
- `素材模版 2`：**【对比道具 A（给别人）】vs【对比道具 B（给自己）】**
  - *例：给孩子买两千块的报班费毫不犹豫，给自己买斤打折苹果挑了十分钟……*

## 附录：例子库（从原文章里摘录的典型例子）

1. 《凌晨两点，我翻完了老公的手机…》中的聊天记录与搜索痕迹；
2. 《老娘做了什么孽，要陪孩子写作业！》中的橡皮擦、撕烂的作业本；
3. 《我用59块，续了自己一条命！！！》中的外卖单与深夜急诊室；
4. 《最高级的浪漫，就是柴米油盐鸡毛蒜皮》中的半夜倒温水、买菜多要一把葱。
