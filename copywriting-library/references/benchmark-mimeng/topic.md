# 选题方法论

## 第一章：规律总结（这个博主在这个维度上有哪些明显规律）

1. **绝对用户中心，严禁自嗨**：选题永远不是“我想表达什么”，而是“大众当下最委屈、最愤怒、最焦虑、最向往什么”。
2. **踩准四大核心痛点**：
   - **代际/亲情撕扯**：为家庭过度付出却被当做理所当然、陪孩子写作业崩溃、婆媳矛盾；
   - **两性亲密关系危机**：冷暴力、出轨、直男敷衍、丧偶式婚姻、前任纠缠；
   - **职场生存与金钱焦虑**：无休止加班、薪资倒挂、老好人被欺负、年轻时如何搞钱；
   - **女性自我意识觉醒**：反抗年龄恐慌、甩掉保姆式人设、多心疼自己、婚恋不将就。
3. **借势热点与生活毛刺**：要么挂钩全网现象级热点人物/社会事件，要么深挖菜市场、朋友圈、微信群等极微小的生活毛刺。

## 第二章：分类/类型（把规律分成几种类型，每种给出例子）

| 选题类型 | 核心心理机制 | 典型代表作 |
| :--- | :--- | :--- |
| **1. 替弱者叫屈/宣泄型** | 替被压榨、被道德绑架、被辜负的人讨回公道 | 《去你大爷，老子真的不想加班了！》《老娘做了什么孽，要陪孩子写作业！》 |
| **2. 认知颠覆/反常识型** | 击碎世俗陈腐教条，给读者松绑 | 《最高级的浪漫，就是柴米油盐鸡毛蒜皮》《女人年轻的时候首先该干嘛？先挣钱！》 |
| **3. 情感窥私/痛点共鸣型** | 挖掘隐秘又普遍的婚恋与人际暗流 | 《凌晨两点，我翻完了老公的手机…》《大多数婚姻不是死于无性，而是死于无话》 |
| **4. 极小代价/实用疗愈型** | 给出极低门槛的心理或生活补偿方案 | 《我用59块，续了自己一条命！！！》《只需200块，让你看起来年薪200万》 |

## 第三章：操作方法（读者怎么用这个规律写自己的文章）

1. **痛点挖掘 3 问法**：
   - 问 1：读者每天在微信群、朋友圈偷偷吐槽什么？
   - 问 2：大家心里都很憋屈但不好意思撕破脸公开说的话是什么？
   - 问 3：这件事里，谁在付出？谁在被占便宜？
2. **反向选题法**：
   - 找出一个被大众默认为“美德”或“必须遵守”的规则（如：孝顺就必须言听计从、女人必须勤俭持家、职场就得忍气吞声）；
   - 从反面切入，替当事人找出合理的“反抗理由”。

## 第四章：公式/模板（可以直接套用的格式）

- `公式 1`：**《不是【常规美德】不行，是你【过度委屈】太久了！》**
- `公式 2`：**《对【某人/工作】太无私，往往是【晚年/人生】不幸的开始！》**
- `公式 3`：**《凭什么【特定人群】能活得痛快，而你却越活越累？》**
- `公式 4`：**《连【基础底线】都保不住，你谈什么【崇高目标】！》**
