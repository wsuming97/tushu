# 金句方法论

## 第一章：规律总结（这个博主在这个维度上有哪些明显规律）

1. **对称与对照美学**：善于使用反义词对仗（如：美貌 vs 热闹、柴米油盐 vs 浪漫、顺境 vs 独处）。
2. **定义型句式占绝对优势**：善用“所谓XX，就是……”给出令人信服的新解释。
3. **字数紧凑**：最具杀伤力的金句字数都在 **14~28 字之间**，极其利于截图、转发朋友圈。

## 第二章：分类/类型（把规律分成几种类型，每种给出例子）

| 金句类型 | 核心修辞机制 | 经典范例 |
| :--- | :--- | :--- |
| **1. 认知颠覆型** | “不是 A，而是 B” | *“不是你在一家单位有饭吃，而是你去任何地方，都有饭吃。”* |
| **2. 常识重构型** | “所谓 A，就是 B” | *“所谓成功，就是有时间照顾自己的小孩。”* |
| **3. 情感亏欠型** | “把所有的 A 给了别人，唯独忘了 B” | *“把所有的耐心给了别人，唯独忘了心疼那个苦了大半辈子的自己。”* |
| **4. 人生退路型** | “不在于 A，而在于 B” | *“手中有钱，心中有界，身旁有友，老后由心。”* |

## 第三章：操作方法（读者怎么用这个规律写自己的文章）

1. **金句打磨 3 步法**：
   - 步 1：提炼一句大白话思想；
   - 步 2：套入“不是……而是……”或“所谓……就是……”模具；
   - 步 3：精简字数，把字数压到 20 字以内，字字掷地有声。

## 第四章：公式/模板（可以直接套用的格式）

- `金句模具 1`：**“所谓的【概念】，根本不是【表象】，而是【内核】。”**
- `金句模具 2`：**“你把所有的【付出】给了【他人】，唯独忘了【心疼自己】。”**
- `金句模具 3`：**“不是【某事】有多难，而是你【被困在原地】太久了。”**
