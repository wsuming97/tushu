# 标题方法论

## 第一章：规律总结（这个博主在这个维度上有哪些明显规律）

1. **短句对仗与反差冲突（占 35.8%）**：前后两截，前半截立假象，后半截给真相。
2. **标点即武器**：全网极高频使用感叹号（！）和问号（？），极少使用温吞句号。
3. **情绪词极化**：大量使用“凭什么、千万别、最、居然、赶紧、彻底、必须”。
4. **数字量化超值感**：用“59块、200块、25岁、40岁、1条命”锚定具体感知。

## 第二章：分类/类型（把规律分成几种类型，每种给出例子）

| 标题类型 | 结构特征 | 典型代表作 |
| :--- | :--- | :--- |
| **1. 前后反差对偶型** | 前半句日常/表象，后半句反转/真相 | 《你的美貌不如你的热闹》《最高级的浪漫，就是柴米油盐鸡毛蒜皮》 |
| **2. 情绪断言咆哮型** | 极致宣泄，带强烈主观态度与感叹号 | 《你支持的不是蒋劲夫，是家暴！》《连陪孩子的时间都没有，你成功个屁啊！》 |
| **3. 灵魂反问挑衅型** | 设问直击痛点，激起好奇与辩驳欲 | 《俞飞鸿徐静蕾，凭什么40岁还能美成18岁？！》《如何对付爱搞暧昧的男人？》 |
| **4. 数字量化锚点型** | 极小成本 vs 极大收益 | 《我用59块，续了自己一条命！！！》《只需200块，让你看起来年薪200万》 |
| **5. 现场引语对话型** | 直球人声对话，极强戏剧张力 | 《吴x波：当我小三吗？送你去坐牢的那种！》 |

## 第三章：操作方法（读者怎么用这个规律写自己的文章）

1. **写标题的“三度法则”**：
   - **痛感度**：读者看到会不会心头一紧（“说的不就是我吗？”）；
   - **态度度**：标题有没有鲜明的立场，绝不模棱两可；
   - **信息差度**：有没有颠覆读者以往的认知。
2. **标题打磨 SOP**：写出 10 个备选标题，去掉所有书面化平铺直叙句，留下带问号、感叹号或前后反差对比的组合。

## 第四章：公式/模板（可以直接套用的格式）

- `模板 A`：**《所谓的【美好表象】，根本不如【大白话真相】！》**
- `模板 B`：**《【某件事】，多 1 秒钟都不能忍！》**
- `模板 C`：**《少买【一件衣服/抽一包烟】，换下半生【活得通透不受气】！》**
- `模板 D`：**《【知名人物/现象】：【最具冲击力的现场台词】！》**
