# 写作风格方法论

## 第一章：规律总结（这个博主在这个维度上有哪些明显规律）

1. **超高短句比（单句均长 18.9 字）**：拒绝超过 25 字的长难从句，多用短句、断句，像坐在读者对面剥花生聊天。
2. **大白话与口语化**：大量使用口语连接词（“说白了、讲真、听我一句劝、讲个大实话、天哪”）。
3. **情绪充沛，立场坚定**：不打官腔、不和稀泥，爱憎分明，替读者骂该骂的人、疼该疼的心。
4. **严格剔除 AI 味**：杜绝空洞的三段式平行排比句（如“跨越岁月，谱写传奇”）。

## 第二章：分类/类型（把规律分成几种类型，每种给出例子）

| 语言风格 | 句式特点 | 经典示范 |
| :--- | :--- | :--- |
| **1. 闺蜜知己聊天风** | 温情、体贴、懂你的辛酸 | *“大半辈子风风雨雨走过来，谁没咬着牙忍过辛酸？”* |
| **2. 犀利清醒大实话** | 刀子嘴豆腐心，一针见血 | *“不是你在一家单位有饭吃，而是你去任何地方，都有饭吃。”* |
| **3. 痛快宣泄痛骂风** | 替弱者出头，宣泄情绪 | *“连陪孩子的时间都没有，你成功个屁啊！”* |

## 第三章：操作方法（读者怎么用这个规律写自己的文章）

1. **朗读消灭书面语**：写完一段文案，必须自己出声读一遍。只要出现舌头打结、气不够喘的地方，立刻加逗号或拆分成两句话。
2. **增加人声颗粒感**：在句子中自然加入口语副词（“其实啊”、“你看”、“说到底”）。

## 第四章：公式/模板（可以直接套用的格式）

- `短句拆解模版`：**【短主谓】。/【逗号短句】。/【一句清醒金句】。**
  - *例：大半辈子为别人忙。到头来两手空空。人过五十，该对自己好一点了。*
