# 故事结构方法论

## 第一章：规律总结（这个博主在这个维度上有哪些明显规律）

1. **小切口、大主题**：故事从不讲宏大史诗，全是从极小的一件事（买一斤水果、陪写一次作业、吵一次架）切入，透视整个时代与人性格局。
2. **情绪过山车曲线**：低谷压抑 ➔ 冲突爆发 ➔ 痛定思痛 ➔ 认知觉醒 ➔ 扬眉吐气。
3. **主角即读者镜像**：故事中的主角往往带有读者的真实痛点（操劳、委屈、节俭、不甘），极易产生代入感。

## 第二章：分类/类型（把规律分成几种类型，每种给出例子）

| 故事模型 | 故事走向与情节弧光 | 经典代表作 |
| :--- | :--- | :--- |
| **1. 辛劳被辜负 ➔ 自我觉醒型** | 倾尽所有付出却被嫌弃 ➔ 痛定思痛做减法 ➔ 活出底气与自由 | 《一个人的老后》系列故事 |
| **2. 忍辱负重 ➔ 绝地翻盘型** | 身处低谷默默积蓄力量 ➔ 抓住关键机会一剑定乾坤 ➔ 扬眉吐气 | 司马懿高平陵之变、苏东坡儋州传记 |
| **3. 虚荣幻灭 ➔ 拥抱真诚型** | 盲目追求虚浮排场 ➔ 遭遇现实重击 ➔ 回归平淡真实的幸福 | 《最高级的浪漫，就是柴米油盐鸡毛蒜皮》 |

## 第三章：操作方法（读者怎么用这个规律写自己的文章）

1. **三幕式故事剪裁法**：
   - **第一幕（日常与危机）**：晨光揉腰、家务琐事、隐藏的家庭裂痕；
   - **第二幕（爆发与刺痛）**：一句扎心的话、一次突发事件（体检异常/儿女顶撞）；
   - **第三幕（觉醒与解药）**：读懂一本书/看清一个道理，从此立规矩、握底牌、活出自我。

## 第四章：公式/模板（可以直接套用的格式）

```text
【困境起点】 一个原本习惯了【默默付出/忍气吞声】的主角……
  ↓
【冲突引爆】 在某天遇到了【极端不公/扎心言论】……
  ↓
【至暗时刻】 深夜一个人关了灯，偷偷叹气……
  ↓
【觉醒顿悟】 读到了【原著核心观点】，突然看透了人情世故……
  ↓
【蜕变新生】 做好住居自立/把死钱变活钱/建立边界，活得从容体面！
```

## 附录：例子库（从原文章里摘录的典型例子）

1. 《最高级的浪漫，就是柴米油盐鸡毛蒜皮》中半夜倒温水的故事；
2. 《我用59块，续了自己一条命！！！》中生病后重新审视健康的故事；
3. 《老娘做了什么孽，要陪孩子写作业！》中鸡飞狗跳的辅导故事。
