# 🛠️ 微信读书与飞书多维表格配置指南 (Feishu & WeRead Setup Guide)

> 本文档用于指导如何配置 **微信读书数据源** 以及 **飞书多维表格（Lark Base）自动化读写**。

---

## 一、微信读书（WeRead）配置说明

### 1. 默认模式（零配置 · 开箱即用 · 推荐 ⭐⭐⭐）
* **无需申请任何 API Key**：系统内置了公开书评智能检索与书籍知识库采样引擎，输入任何书名，AI 会自动检索并聚类该书的 20~40 条真实高赞长评与读者痛点。
* **适用场景**：日常图书带货文案创作、痛点提炼、金句提取。

### 2. 个人书架与划线同步模式（可选进阶）
* 若需同步您个人微信读书账号中的**私人划线笔记、书架**：
  1. 浏览器网页端登录 [微信读书 (weread.qq.com)](https://weread.qq.com/)；
  2. 按 `F12` 打开开发者工具，在 `Application -> Cookies` 中复制 `wr_skey` 或 `wr_vid`；
  3. 填入 `copywriting-library/.env` 中的 `WEREAD_COOKIE`。

## 二、飞书多维表格（Lark Base）3 分钟配置指南

通过配置飞书自建机器人，AI 可以将生成好的口播稿、四平台文案、评分与成片链接**全自动写入飞书多维表格**，实现团队可视化协同。

```mermaid
graph LR
    A["飞书开放平台<br/>创建自建应用"] --> B["获取 App ID & Secret"]
    B --> C["开启多维表格读写权限"]
    C --> D["将应用添加为表格协作者"]
    D --> E["配置本地 .env 文件"]
    E --> F["一键全自动双向同步"]
```

### 第 1 步：在飞书开放平台创建应用
1. 访问并登录 [飞书开放平台 (open.feishu.cn)](https://open.feishu.cn/)；
2. 点击右上角 **【创建企业自建应用】**：
   * **应用名称**：`图书内容创作引擎`（可自定义）
   * **应用描述**：`用于图书带货文案与视频自动化同步`
3. 创建完成后，在 **【凭证与基础信息】** 页面获取：
   * **`App ID`**（形如 `cli_a1b2c3d4e5...`）
   * **`App Secret`**（点击查看并复制）

---

### 第 2 步：开启多维表格权限并发布应用
1. 在左侧菜单点击 **【权限管理】**；
2. 搜索并开通以下 **多维表格** 读写权限：
   * ✅ `多维表格 (bitable:app)` 或 `查看、编辑多维表格`
   * ✅ `查看多维表格 (base:table:read)`
   * ✅ `编辑多维表格记录 (base:record:write)`
   * ✅ `查看多维表格记录 (base:record:read)`
3. 在左侧菜单点击 **【版本管理与发布】** ➔ 点击 **【创建版本】** ➔ 输入版本号（如 `1.0.0`）➔ 点击 **【申请发布】**（企业内自建应用通常自动免审即时生效）。

---

### 第 3 步：把应用添加为多维表格协作者（关键步骤！）
1. 打开您日常使用的 **飞书多维表格网页**；
2. 点击右上角的 **`...`（更多）** ➔ 选择 **【添加文档助手 / 应用】**（或在协作者中添加应用）；
3. 搜索刚才创建的 `图书内容创作引擎` 机器人，点击添加并赋予 **【编辑】** 权限。

---

### 第 4 步：在本地配置 `.env` 文件

在 `copywriting-library/` 目录下创建或修改 `.env` 文件：

```ini
# 飞书应用凭证
FEISHU_APP_ID=cli_xxxxxxxxxxxxxxxx
FEISHU_APP_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# 飞书多维表格 Base 链接
FEISHU_BASE_URL=https://your-domain.feishu.cn/base/bascnxxxxxxxxxxx
```

## 三、飞书多维表格推荐字段模版

建议在飞书多维表格中建好以下字段（AI 脚本会自动映射回填）：

| 字段名称 | 字段类型 | 填充内容 |
| :--- | :---: | :--- |
| **书名/主题** | 文本 | 书籍名称（如《一个人的老后》） |
| **深度带货口播稿** | 多行文本 | 12 分钟逐幕分镜头文案 |
| **爆款流量口播稿** | 多行文本 | 4 分钟金句文案 |
| **带货款四平台文案** | 多行文本 | 微信视频号+快手+抖音+小红书文案 |
| **流量款四平台文案** | 多行文本 | 微信视频号+快手+抖音+小红书文案 |
| **质检评分** | 数字/进度 | 6 维质检得分（如 97） |
| **审核状态** | 单选标签 | `待审核` / `已通过` / `需修改` |
| **成片视频链接** | 附件/URL | 最终渲染生成的 MP4 文件路径/链接 |
