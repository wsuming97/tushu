# 📚 微信读书与飞书多维表格对接说明规范

> 本指南用于规范图书带货流水线中的数据输入与飞书看板对接。

---

## 一、微信读书读者书评调研说明

* **官方 Gateway 真实采样**：系统接入腾讯微信读书官方 Gateway（`POST https://i.weread.qq.com/api/agent/gateway`），支持输入书名真实检索该书的**当前单次最多 10 条**真实热门长评与读者痛点。
* **凭据与授权**：真实采样需在环境变量中配置 `WEREAD_API_KEY`；若未配置，支持通过 `--input` 传入本地导出的书评文件，或显式指定 `--conceptual` 进行概念推演。

---

## 二、飞书多维表格看板对接说明

* **当前支持模式**：**默认只读预览模式 (`--dry-run`)**。
* **执行规范**：
  - 运行 `python scripts/lark_base_sync.py --book "书名" --score 88.5` 默认输出结构化 Markdown 表格预览，不发起外部写库网络请求；
  - 飞书企业自建应用真实写入能力（`--apply`）尚在开发对接中，当前传入 `--apply` 将显式返回 `status=not_implemented` 并阻断退出。
