## 🛡️ 素材库准入与质量门禁（入库铁律）

所有进入本素材库的文案，**必须经过严格的四步闭环审核流，未完成二、三步审核的稿件严禁入库**：

```text
【第 1 步：初稿生成】
       │ （仅内部生成，不写入素材库）
       ▼
【第 2 步：事实核验与质量优化】（copywriting-verify-optimize 技能）
       │ • 6 维度评分（满分100，优化后须 ≥85 分）
       │ • 建立主张台账，去除伪引语、伪数据与夸大承诺
       ▼
【第 3 步：平台合规与风控自审】（协同 publish-precheck 规范）
       │ • 严禁编造虚假家庭纠纷与极端对立
       │ • 严禁恐吓式/诅咒式卖惨带货
       │ • 严禁道德绑架与极端站队式强迫互动
       │ • 全面贯彻“三大核心视角转变”（母亲自立对家庭负责、两代人双赢、提供生活决策指南）
       ▼
【第 4 步：审核完毕，正式入库保留】
         写入 copywriting-library/topics/<书名>/ 永久存档
```
