# 📐 双轨内容生产规范 (Dual-Track Content Production Protocol)

> **核心原则**：针对任何一本书籍或主题，必须同时输出一套 **“深度带货长视频”** + 一套 **“高爆发流量短视频”**，形成公域拉新与私域/挂车转化的商业闭环。

---

## 1. 双轨模式全貌对照

| 维度 | 轨道 A：深度带货长视频 (`full_commerce`) | 轨道 B：爆款流量短视频 (`viral_short`) |
| :--- | :--- | :--- |
| **视频时长** | **4 ~ 8 分钟**（中长视频沉浸精讲） | **1 ~ 1.5 分钟**（60~90秒短平快） |
| **文案字数** | 1,000 ~ 1,800 字 | 280 ~ 380 字 |
| **核心算法目标** | **高时长完播率、高信任度、高挂车转化率** | **高前5秒留存率、高点赞率、高评论转发率** |
| **叙事模型** | **五段式黄金转化模型**（认知颠覆→痛点展开→4大硬核方案→情绪升华→促单闭环） | **三段式爆破模型**（3秒钩子拷问→单一痛点穿透→颠覆认知金句→评论互动留钩） |
| **带货形态** | 视频左下角挂车、橱窗强引导购买实体书 | 评论区置顶引导、主页引流、粉丝关注沉淀 |
| **分镜画面数** | 6 ~ 10 幕深度分镜 | 3 ~ 4 幕高张力分镜 |

---

## 2. 批量生产标准化工作流 (Standard Workflow)

以后针对任何新书（如《人生由我》、《你当像鸟飞往你的山》、《人间值得》等），技能将自动执行以下标准化双轨产出：

```text
输入：书籍名称 / 核心章节 / 痛点素材
  │
  ├──► [轨道 A] 自动生成：深度带货长文案 + 分镜头脚本 (挂车带货)
  │      └── 配套：0.80语速深夜电台配音 + 完整白板/绘本画面
  │
  ├──► [轨道 B] 自动生成：1分钟垂直细分流量短文案 + 互动脚本 (吸粉爆流)
  │      └── 配套：快节奏治愈配音 + 核心金句大字卡片 + 评论区置顶话术
  │
  └──► [自动配套] 每条视频稿完成时同步生成三平台发布文案
         ├── 抖音：30字以内标题 + 正文 + 话题标签(10个) + 小黄车话术(带货款)
         ├── 视频号：完整标题(含书名) + 长文案 + 话题标签(5~6个)
         └── 小红书：20字emoji标题 + 封面文案建议 + 笔记正文 + 话题标签(10个)
```

> **关键约束**：发布文案写完后须经 `publish-precheck` 扫描，修复绝对化用语等违规候选后再归档。

## 3. 标准目录归档格式

每个图书项目在文案素材库中的标准归档结构：

```text
copywriting-library/topics/<书籍名称>/
├── 01_认知觉醒篇_口播稿.md          # 轨道 A 深度带货口播稿
├── 01_流量爆款短视频文案_xxx.md      # 轨道 B 流量吸粉口播稿
├── 01_发布文案_带货款.md             # 轨道 A 三平台发布文案（抖音+视频号+小红书）
├── 01_发布文案_流量款.md             # 轨道 B 三平台发布文案（抖音+视频号+小红书）
├── 02_xxx_口播稿.md                 # 下一期带货口播稿
├── 02_流量爆款短视频文案_xxx.md      # 下一期流量口播稿
├── 02_发布文案_带货款.md             # 下一期带货发布文案
├── 02_发布文案_流量款.md             # 下一期流量发布文案
└── ...
```

> **命名规则**：序号对齐（`01_` / `02_`），同一期的口播稿与发布文案共享相同序号，方便按期管理。
